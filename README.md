# Atlas Curieux — version complète

Site éducatif interactif prêt pour GitHub Pages.

## Contenu
- 8 pages HTML : accueil, explorer, quiz, missions, progression, bibliothèque, musique, paramètres
- `assets/css/style.css`
- `assets/js/app.js`
- 3 vrais morceaux MP3 chill créés pour le projet et stockés localement dans `assets/audio/`
- 5 illustrations SVG originales dans `assets/img/`
- XP, niveaux, badges, missions, favoris et bibliothèque via `localStorage`
- Lecteur : play/pause, précédent/suivant, mute, volume 0–100 %, progression, lecture auto, aléatoire et répétition

## GitHub Pages
Mettre tout le contenu du dossier à la racine du dépôt, puis activer **Settings → Pages → Deploy from a branch → main → / (root)**.

## Audio
Les trois MP3 sont des compositions originales générées pour ce projet et incluses dans le dépôt. Aucun service audio externe n'est requis.


## Images documentaires
Les pages Explorer/Bibliothèque utilisent désormais des images réelles provenant de sources institutionnelles ou de Wikimedia Commons, avec crédit et indication de licence lorsque disponible. Voir `sources-images.html`.

Les images sont affichées au niveau de chaque découverte (carte + lecteur), afin de contextualiser le fait au moment où il est expliqué. Les sources sont visibles dans les crédits et la page `sources-images.html`.
