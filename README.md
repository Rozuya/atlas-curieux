# Atlas Curieux — version complète

Site éducatif interactif statique, conçu pour GitHub Pages.

## Pages
- index.html — accueil
- explorer.html — exploration et lecteur de cartes
- quiz.html — quiz chronométré
- missions.html — missions et badges
- bibliotheque.html — connaissances découvertes + recherche
- progression.html — niveau, XP et statistiques
- musique.html — radio chill intégrée
- parametres.html — thème, lecture et données

## Audio
Le lecteur utilise la Web Audio API pour générer 3 ambiances synthétiques directement dans le navigateur. Il y a Play/Pause, précédent/suivant, mute indirect via 0 %, volume 0–100 %, playlist et lecteur flottant sur toutes les pages.

## Déploiement GitHub Pages
1. Crée un dépôt public GitHub.
2. Dépose tout le contenu du dossier à la racine du dépôt.
3. Settings → Pages → Deploy from branch → `main` / `/root`.
4. Attends le déploiement GitHub Pages.

Aucun backend n'est requis.
